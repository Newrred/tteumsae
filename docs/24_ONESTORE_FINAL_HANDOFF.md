이 버전은 기기 현재 위치를 사용하지 않고 사용자가 선택한 출발지를 기준으로 계산합니다. ‘현재 교통으로 다시 확인’도 같은 출발지 기준이므로 실제 출발 장소가 달라지면 입력을 수정해 주세요. 출발 알림은 선택 기능이며 알림 권한을 거부해도 검색·추천·외부 길 안내를 이용할 수 있습니다. 기기 절전 설정 등에 따라 알림이 늦어질 수 있습니다.

## 6. 복사 가능한 검증팀 참고사항

대상은 틈새 Android 0.13.0 / versionCode 33 / com.tteumsae.app입니다. 출발지를 직접 검색·선택하는 수동 버전으로, 기기 GPS 취득과 위치 권한 요청을 하지 않습니다. 사용자가 선택한 공개 장소 좌표는 서버로 전송해 경로와 경유지 후보를 계산합니다. 인터넷 인프라의 IP 등 보안 로그 처리는 개인정보처리방침에 안내했습니다. 모든 좌표나 개인정보의 서버 처리가 없다는 뜻은 아닙니다.

핵심 기능은 로그인 없이 사용할 수 있어 공용 테스트 계정이 필요하지 않습니다. 실제 차량 운행 없이 다음 순서로 확인할 수 있습니다.

1. 앱 실행 후 목적지 검색으로 들어갑니다.
2. 출발지 ‘강릉역’, 목적지 ‘경포대’를 검색해 각각 결과를 선택합니다. 공개 관광 예시로 ‘안목해변’ → ‘경포대’도 사용할 수 있습니다.
3. 도착 시각은 검사하는 현재 시각보다 약 2시간 이후로 설정합니다. 관심 필터는 선택하지 않아도 됩니다.
4. 틈새 찾기로 결과를 확인합니다. 운영시간·교통·현재 시각에 따라 후보 수와 장소가 달라집니다. 후보가 없으면 입력 수정 또는 목적지 직행을 사용할 수 있습니다.
5. 후보 한 곳의 체류·출발 안내, 지도/목록 왕복, 상세 보기와 뒤로 이동을 확인합니다.
6. 카카오맵 길 안내를 누르면 선택한 출발지·경유지 한 곳·목적지가 외부 앱 또는 연결 페이지로 전달됩니다. 실제 운행은 필요하지 않습니다.
7. 장소 탐색의 저장/해제, 설정의 개인정보처리방침·문의·데이터 출처·오픈소스 라이선스를 확인합니다.
8. 선택 로그인은 설정의 계정 영역에 있으며 추천 필수 단계가 아닙니다. 운영자 개인 계정을 검증용 계정으로 제공하지 않습니다.
9. 현재 교통으로 다시 확인은 선택한 출발점·목적지 기준으로 갱신합니다. 실제 현재 위치로 출발지가 자동 변경되지 않는 것이 정상 동작입니다.

선택 알림은 정확한 알람 권한을 사용하지 않으며 기기 상태에 따라 늦어질 수 있습니다. 최종 실기기 검사에서도 약 3분 지연 수신 후 정상 경로 전달을 확인했습니다. 자동 위치 코드는 별도 빌드로 보존돼 있지만 이 수동 APK에서 원격으로 켜는 구조가 아닙니다. 향후 자동 위치를 제공한다면 필요한 절차와 검증을 갖춘 새로운 버전으로 제출합니다.
