# 현재 개발 상태

## 구현된 핵심 기능

- 카카오맵 Android SDK 지도 표시
- GPS 권한 요청, 현재 위치 표시, 다시 눌러 비활성화
- 이동 틈새 탐색과 근처 틈새 탐색 분리
- 출발지·목적지 카카오 장소 검색과 검색 결과 선택
- 15~360분 슬라이더와 숫자 직접 입력
- 차량·도보 조건과 이동 후 안전 여유시간
- 활동 유형 필터와 휴식·식사 제외 조건
- TourAPI 장소·대표 이미지 기반 카드
- 이동 탐색 자동차 경유지 카카오맵 연결
- 근처 탐색 도보·차량 좌표 길안내
- 근처 탐색 시 강원도 행정구역 검증
- 카드 선택 번호와 지도 마커 동기화
- 저장 장소 목록 추가 로딩
- 로딩·빈 결과·오류 화면
- 최소 설정 화면

## 다음 우선순위

1. 결과 카드 선택과 지도 마커·카메라 동기화 세부 QA
2. 실제 기기에서 이동/근처 탐색 전체 흐름 QA와 문구 조정
3. 설정 탭 최종 정보 구조와 디자인 적용
4. 고령자 동반·무장애 시설 데이터 연동
5. 네트워크 오류와 위치 권한 거부·영구 거부 안내 보강
6. 개인정보처리방침·위치기반서비스 약관 공개 URL 준비
7. 앱 아이콘·스플래시·접근성 설명 점검
8. targetSdk 36 전환과 실제 기기 회귀 테스트
9. 릴리스 키·Play App Signing·AAB 생성

## 검증 상태

- 백엔드 Node 테스트 15개 통과
- Android Kotlin 및 단위 테스트 소스 컴파일 통과
- Android 디버그 APK 빌드 통과
- 기존 한글 작업 경로에서는 Gradle JUnit 실행기가 테스트 클래스에 `ClassNotFoundException`을 일으켰습니다. 새 컴퓨터의 영문 경로에서 다시 실행하세요.

## 데이터 및 동기화

- TourAPI `KorService2`, 강원도 `areaCode=32`
- Vercel Cron이 TourAPI 기본·상세 데이터를 Supabase에 동기화
- 저장 대표 이미지는 일반 목록의 썸네일과 상세 동기화 결과 사용
- 고령자·무장애 시설 태그는 아직 별도 API 연동 전
