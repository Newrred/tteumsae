버전에 관한 것이다. 기존 묶음을 code34 검증본으로 이름만 바꾸거나 내부 APK만 교체하지 않는다.

현재 검토 대상은 **0.13.1 / code34 / 수동 출발지 선택형**이다. 마지막 지도 겹침 보완을 포함한
최종30E0의 빌드·설치·주소/시트 및 묶음 핀 실기기 검사와 **06:39 공개 APK 교체·익명 다운로드
해시 대조**를 완료했다. [원스토어 인수인계](24_ONESTORE_FINAL_HANDOFF.md)의 실제 업로드 대상도
code34로 갱신했다. 과거 code33을 그대로 올리라는 지시로 해석하지 않는다.
단, 기존 설명서·권리PDF·공유 ZIP은 이번 작업에서 새로 만들지 않았고 현재code34를 포함하지 않는다.

## 2. 사용자가 확인할 변화

1. **도로명·지번 주소 검색:** 장소명뿐 아니라 주소 자체를 찾아 선택할 수 있다. 주소와 장소
   결과를 구분하며 도로명·지번 정보를 함께 보여준다.
2. **지도와 목록의 연결:** 결과 화면에서 지도를 유지한 채 하나의 시트를 접힘·중간·펼침으로
   전환한다. 지도/목록 왕복 자체로 전체 경로를 강제로 다시 맞추거나 읽던 목록을 초기화하지 않는다.
3. **선택 행동의 연속성:** 같은 카드의 같은 버튼 영역에서 선택·선택됨을 표시하고 상세보기와
   구분한다. 지도 핀 선택은 해당 카드를 보여주며, 묶음 탐색 자체로 기존 선택·알림을 해제하지 않는다.

디자인 분위기, 차량 이동·경유지 한 곳, 선택 출발지 기준 재계산, 관광 상세 정보, 기기 저장,
선택 로그인·알림이라는 범위는 유지한다. 기기 GPS 취득이나 위치 권한 요청을 추가한 버전이 아니다.
**상세 왕복에서는 시트·목록 상태를 복원하지만, MapView가 재생성되므로 카메라 위치·확대 배율은
보존하지 않는다.** 결과 화면 안의 지도/목록 왕복과 이 제한을 구분한다.

## 5. 새 공유 묶음의 최소 구성과 보안

기존 code33 묶음은 보존하고, 새 묶음을 만들 때에는 **변경 안내를 첫 파일**로 둔다.
최종 code34 APK, 갱신한 docs23/24/26/27/28, 실제 최종 화면과 새로운 MANIFEST를 포함한다.
기존 설명서·권리 자료를 참고용으로 포함하면 파일별 대상 버전을 명시한다.

기존 묶음 생성 스크립트는 code33 APK·해시·소스 커밋을 고정하므로 설정을 검토하지 않은
재실행으로 새 버전 묶음을 만들지 않는다. docs27/28을 포함하고 서로 다른 폴더로 복사된
Markdown의 상대 링크도 검사한다. APK의 공개 클라이언트 설정과 서버 비밀키를 구분한다.
**TourAPI·서버 비밀키, 환경 파일, 서명키·서명 백업, 인증 토큰, 개인 계정 화면·원본 로그는
공유 대상이 아니다.**

최종 업로드 절차는 [원스토어 인수인계](24_ONESTORE_FINAL_HANDOFF.md), 검토 위험과 미검증
범위는 [출시 검토 위험](26_RELEASE_REVIEW_RISKS.md), 후보별 원인·검증 이력은
[사용성 보완 기록](27_RELEASE_UX_REFINEMENT.md)을 함께 본다.
